# 产品概述

## 项目定位

AI Interviewer 是一款**本地运行的 JavaFX AI 技术面试训练工具**。

它**不是**：
- SaaS 平台或在线服务
- 招聘系统或面试管理工具
- 云端 AI 面试服务

它是：
- 一个可重复、可量化的个人面试训练工具
- 一个本地运行的桌面应用
- 一个帮助你系统化提升技术面试能力的 AI 助手

## 核心能力

### 1. 简历智能分析

上传 PDF/DOCX/Markdown/TXT 格式的简历，系统通过 Apache Tika 提取文本内容，再由 AI 分析生成候选人画像（CandidateProfile），包含：

- 技能栈分析
- 项目经验提取
- 技术背景总结
- 工作经历梳理

### 2. AI 技术面试

基于 LangGraph4j 状态机驱动的智能面试流程：

- **自动流程生成**：根据简历 + 岗位要求 + 面试规则自动生成面试方案
- **流式 AI 提问**：实时流式输出 AI 生成的面试问题
- **智能追问**：AI 根据回答质量决定是否深入追问
- **阶段转换**：自动在不同面试阶段间转换
- **暂停恢复**：支持面试中断后从断点继续
- **Checkpoint 机制**：完整的状态序列化和恢复能力

### 3. RAG 知识增强

上传知识文档（技术文档、笔记、项目资料等），系统自动处理：

```
文档 → Tika 解析 → 文本分块 → Embedding 向量化 → Lucene 索引
                                                          ↓
面试时 Agent 查询 ← 向量相似度搜索 ← 用户知识库
```

让 AI 生成的问题更贴合你的技术背景和项目经验。

### 4. 六维评估报告

面试结束后自动生成 Markdown 格式评估报告，包含六个维度的评分：

| 维度 | 说明 |
|------|------|
| 技术能力 | 编程语言、框架、工具的掌握程度 |
| 问题解决 | 分析问题、设计方案的能力 |
| 项目经验 | 实际项目中的技术深度和广度 |
| 系统设计 | 架构设计、技术选型的能力 |
| 沟通表达 | 技术表达的清晰度和逻辑性 |
| 综合评价 | 整体表现和发展建议 |

### 5. 本地数据隔离

- 所有数据存储在本地 SQLite 数据库
- 每个用户拥有独立的文件目录
- 用户间数据严格隔离
- 无需联网即可使用
- 隐私安全有保障

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Java | 21 | 运行时 |
| Spring Boot | 4.1.0 | 应用框架 |
| JavaFX | 21.0.11 | 桌面 UI |
| SQLite | - | 本地数据库 |
| MyBatis | 4.0.0 | SQL 映射 |
| Flyway | 12.10.0 | 数据库迁移 |
| Spring AI | 2.0.0 | AI 服务集成 |
| LangGraph4j | 1.8.20 | Agent 状态机 |
| Apache Tika | 3.2.3 | 文档解析 |
| Apache Lucene | 10.3.2 | 向量存储 |

## 运行模型

```
用户 → JavaFX 界面 → Spring Boot 服务层 → SQLite 数据库
                          ↓
                    Spring AI (LLM)
                          ↓
                    Lucene 向量索引
```

单进程架构，Spring Boot 管理所有 Bean 和生命周期，JavaFX 提供用户界面。无 Web 服务器，无外部依赖。
