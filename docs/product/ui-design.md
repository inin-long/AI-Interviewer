# UI 设计规范

## 设计理念

AI Interviewer 的 UI 设计遵循以下核心关键词：

> **专业、专注、理性、轻量、可信赖、技术感、低干扰**

定位为**现代桌面工作台**风格。中性背景、清晰边界与层次、适中信息密度、蓝紫色点缀表达 AI 属性。

---

## 色彩系统

### 亮色主题（默认）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#F6F7F9` | 略冷浅灰，非纯白 |
| 表面 | `#FFFFFF` | 白色卡片/面板 |
| 边框 | `#E4E6EA` | 近灰色边界 |
| 主文字 | `#1A1D21` | 深色文本 |
| 次要文字 | `#6B7280` | 辅助说明 |
| 品牌主色 | `#4F63D9` | 蓝紫色，表达技术/AI/理性 |

### 状态色彩

| 状态 | 色值 | 使用场景 |
|------|------|----------|
| 成功 | 绿色系 | 连接成功、解析完成、面试完成 |
| 警告 | 琥珀色系 | 倒计时警告、任务延迟 |
| 错误 | 红色系 | 连接失败、解析失败、任务失败 |
| 信息 | 蓝色系 | 面试阶段提示、评分提示 |

**原则**：状态色仅用于状态表达，不做装饰性使用。品牌主色占据页面面积不超过 10%。

### 暗色主题

暗色主题不是简单的颜色反转，有独立的表面层次体系：

| 用途 | 色值 |
|------|------|
| 背景 | `#111318` |
| 主表面 | `#191C23` |
| 次表面 | `#22252D` |
| 边框 | `#2E313A` |

暗色主题特别适合长时间面试和代码编辑场景。

## 排版

### 字体栈

| 用途 | 字体 |
|------|------|
| 正文 | Segoe UI / Microsoft YaHei UI / sans-serif |
| 代码 | Cascadia Mono / Consolas / monospace |

### 字号层级

| 层级 | 字号 | 用途 |
|------|------|------|
| 大标题 | 24px | 页面标题 |
| 模块标题 | 18px | 功能模块 |
| 卡片标题 | 15px | 卡片/列表项 |
| 正文 | 14px | 主要内容 |
| 辅助文字 | 12px | 说明、标签 |
| 代码 | 13px | 代码块 |

## 组件风格

### 圆角

| 元素 | 圆角 |
|------|------|
| 输入框/按钮 | 7px |
| 卡片 | 10px |
| 弹窗 | 12px |
| 状态标签 | 999px（全圆角） |

### 阴影

尽量少用阴影，用边界分层。仅在弹窗、下拉菜单、浮动面板、Tooltip 上使用轻量阴影。

### 图标

- 统一细线图标风格
- 默认 18px，紧凑 16px
- 空状态 32-40px
- 不使用 Emoji 作为功能图标

## 主框架布局

单窗口 + 固定左侧导航：

```
┌────────────────────────────────────────────┐
│              顶部栏 (56px)                  │
│         标题 | 状态 | AI连接 | 用户         │
├──────────┬─────────────────────────────────┤
│          │                                 │
│  左侧导航 │         主内容区域              │
│  216px   │        (最大 1440px)            │
│  (可折叠) │                                 │
│   64px   │                                 │
│          │                                 │
└──────────┴─────────────────────────────────┘
```

- 页面内边距：水平 28px，垂直 24px
- 最小窗口宽度：1024px
- 导航项：首页、面试方案、面试记录、简历、知识库、设置
- 报告从面试记录中访问（非独立导航项）

## 核心页面设计

### 首页

**定位**：行动导向，非数据仪表盘。

- 问候语 + CTA 按钮（开始面试 / 创建方案）
- 三个区块：未完成面试、最近方案、上次面试结果
- 状态信息条："3 份简历，12 篇知识文档，AI 服务正常"

### 面试方案页

**列表式**布局（非大卡片），每行 88-104px：

- 方案名称、岗位信息、难度、时长、简历、重点方向、上次使用时间、操作按钮
- 创建/编辑使用全内容页面，双栏布局：左=配置表单，右=方案摘要

### 面试页面（核心）

**专注模式**：左侧导航自动折叠或隐藏，顶部栏极简。

```
┌──────────────────────────────────────────────────┐
│ 对话历史 (文档流式)        │ 信息栏 (~260px)      │
│                           │ - 当前阶段            │
│ AI 面试官: 请介绍...      │ - 面试进度            │
│                           │ - 剩余时间            │
│ 你: 我的项目经验...       │ - 当前简历            │
│                           │ - Token 消耗          │
│                           │ - 引用资料            │
├──────────────────────────────────────────────────┤
│ 输入区域 (专业编辑器风格)                         │
│ [+] 代码回答 | 草稿 | Ctrl+Enter 发送            │
└──────────────────────────────────────────────────┘
```

- 对话使用**文档流式**布局（非聊天气泡），用角色标签 + 背景色 + 左侧边线区分
- 输入区域：最小 96px，最大 ~240px，自动扩展
- 生成中时：发送按钮变为"停止生成"

### 报告页面

**正式评估文档**风格，非数据仪表盘：

- 左侧边栏 = 报告目录
- 主区域 = 评分 + 雷达图 + 5 个横向评分条 + 评价文本
- 评分项可点击跳转到对应问答（报告-对话联动）
- 不足之处以整齐标签展示

### 设置页面

传统桌面设置布局，分组：

- 通用（主题、窗口、快捷键）
- AI 服务（Base URL、API Key、聊天模型、Embedding 模型、连接测试）
- 网络（代理）
- 数据（目录）

## 动画原则

动画仅服务于状态理解，不追求"AI 感"。

| 推荐 | 不推荐 |
|------|--------|
| 流式输出光标 | 粒子背景 |
| 加载骨架屏 | 呼吸边框 |
| 平滑进度条 | 鼠标跟随效果 |
| 阶段转换 | 长渐变动画 |
| 面板展开/折叠 | 全页滑动 |
| 状态标签淡入 | 卡片悬浮浮动 |

推荐时长：按钮 100-140ms，页面切换 160-200ms，侧边栏 180-220ms，弹窗 160ms，Toast 180ms。

---

## 响应式策略

| 窗口宽度 | 策略 |
|----------|------|
| ≥1280px | 完整导航展开，信息栏可见，表格列完整 |
| 1024-1279px | 导航可折叠，信息栏默认隐藏，次要列隐藏 |
| <1024px | 强制最小窗口宽度，不尝试移动布局 |

**原则**：合理的缩放和信息降级，不做移动端适配。
