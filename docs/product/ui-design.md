# AI Interviewer UI 设计标准

> 版本：1.0（锁定）
>
> 状态：项目唯一视觉规范
>
> 生效范围：登录、注册、主框架、全部业务页面、弹窗、抽屉、空状态和后续新增页面

本规范以以下两张页面为最终视觉基准：

- [简历中心基准图](../ui-reference/ui-standard-resume.png)
- [面试技巧库基准图](../ui-reference/ui-standard-skills.png)

任何页面不得自行增加新的颜色、字号、圆角、阴影、图标体系或插画风格。确需新增语义时，必须先扩展本规范和 `src/main/resources/css/app.css` 中的根令牌，再由页面引用；禁止在 FXML 中写内联样式。

## 1. 设计原则

- 专业、克制、可信赖：冷白工作区、白色表面、深色文字和低饱和靛蓝强调。
- 信息优先：主要动作清楚，次要操作降低对比度，装饰不抢占内容。
- 高密度但不拥挤：使用稳定的 4px 间距网格和明确的文字层级。
- 边框优先、阴影辅助：常规卡片以 1px 边框分层，只使用极轻阴影。
- 组件一致：同一语义在全部页面保持相同高度、圆角、字号、图标和状态反馈。
- 业务数据真实：设计态示例不得写入业务代码，不为视觉效果伪造状态。

## 2. 设计令牌

令牌定义在 `app.css` 的 `.root` 中。下表是唯一允许使用的基础色。

### 2.1 色彩

| 令牌 | 色值 | 用途 |
|---|---:|---|
| `-app-background` | `#F8FAFD` | 应用工作区背景 |
| `-surface` | `#FFFFFF` | 卡片、面板、输入框、弹层 |
| `-surface-muted` | `#F7F9FC` | 表头、弱分区背景 |
| `-surface-soft` | `#F3F5FF` | 品牌弱强调区域 |
| `-hover` | `#F5F6FA` | 中性悬停 |
| `-border` | `#E1E5EC` | 默认边框和分割线 |
| `-border-strong` | `#CDD4E0` | 输入框和较强边界 |
| `-border-focus` | `#5969F6` | 焦点边框 |
| `-text` | `#151B2D` | 标题和正文 |
| `-text-secondary` | `#667085` | 说明和辅助信息 |
| `-text-muted` | `#98A2B3` | 时间、占位和弱提示 |
| `-primary` | `#5364F2` | 主按钮、选中态、关键链接 |
| `-primary-hover` | `#4656DC` | 主色悬停 |
| `-primary-pressed` | `#3D4CC8` | 主色按下 |
| `-primary-soft` | `#F0F1FF` | 导航选中、弱选中背景 |
| `-success` | `#2DBE82` | 成功、已完成、在线 |
| `-warning` | `#F5A623` | 待处理、提示 |
| `-danger` | `#E85D68` | 失败、删除、错误 |
| `-info` | `#3478F6` | 信息和处理中 |

规则：

- 品牌主色在单页可见面积中不超过约 10%。
- 状态色只表达状态，不用于无语义装饰。
- 正文不得使用纯黑；工作区不得使用纯白作为整页背景。
- 页面不得直接写十六进制颜色；新增颜色必须先登记为令牌。

### 2.2 间距

所有间距从以下网格取值：

| 级别 | 尺寸 | 典型用途 |
|---|---:|---|
| XS | 4px | 标题与辅助信息、紧凑内容 |
| S | 8px | 图标与文字、标签间距 |
| M | 12px | 控件组、卡片内部紧凑间距 |
| L | 16px | 标准卡片内边距、区块间距 |
| XL | 24px | 页面水平内边距、主区块间距 |
| 2XL | 32px | 大区块和弹窗内边距 |

页面默认内边距为 `20px 24px`。列表和工具栏优先使用 8/12px，卡片优先使用 12/16px。禁止使用没有明确目的的 5、7、11、13、17、19px 布局间距。

### 2.3 圆角与边框

| 元素 | 圆角 | 边框 |
|---|---:|---|
| 按钮、输入框、选择器 | 8px | 1px `-border` |
| 卡片、列表面板 | 10px | 1px `-border` |
| 对话框、抽屉内浮层 | 12px | 1px `-border` |
| 标签、筛选项、头像 | 999px | 按语义决定 |

常规卡片使用 `-shadow-card`；菜单、选择器弹层使用 `-shadow-pop`；模态窗口使用 `-shadow-dialog`。不得为普通卡片增加重阴影或悬浮位移动画。

## 3. 文字层级

字体栈固定为 `"Microsoft YaHei UI", "Segoe UI", sans-serif`，代码字体使用 `"Cascadia Mono", "Consolas", monospace`。

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| 页面标题 | 28px / 800 | 每页唯一主标题 |
| 顶栏标题 | 21px / 700 | 当前导航名称 |
| 模块标题 | 16px / 700 | 卡片或内容区标题 |
| 卡片标题 | 14px / 700 | 列表项和卡片主信息 |
| 正文 | 14px / 400–500 | 主要内容 |
| 辅助说明 | 13px / 400 | 页面副标题、摘要 |
| 标签与元信息 | 12px / 600 | 状态、日期、标签 |
| 最小辅助信息 | 11px / 500 | 仅限紧凑卡片中的非关键元信息 |

规则：

- 页面标题只出现一次；模块标题不得模拟页面标题。
- 大段正文优先换行，不用缩小字号解决空间不足。
- 时间、计数单位和说明使用次要色；重要数值使用主文字色。
- 中文与英文混排时，英文缩写两侧保留自然空格。

## 4. 主框架

- 左侧导航：固定宽度 220px，白色背景，右侧 1px 边框。
- 品牌区：36px 应用图标，品牌文字 17px / 700。
- 导航项：高度 50px、圆角 8px、图标 19px；选中态使用 `-primary-soft` 和左侧 3px 主色标识。
- 顶栏：高度 62px，白色背景，底部 1px 边框。
- 内容区：`-app-background`，页面默认内边距 `20px 24px`。
- 主窗口默认尺寸 1440×820，最小尺寸 1024×720；桌面布局不做移动端重排。

面试进行中的专注模式可以隐藏普通导航，但仍必须复用本规范的颜色、文字和通用组件；面试工作台的结构尺寸由其专属规则锁定。

## 5. 通用组件

### 5.1 按钮

- 主按钮：40px 高，主色实底，白字，13px / 700，图标 17–18px。
- 次按钮：40px 高，白底、灰边、深色文字；悬停使用主色弱背景。
- 图标按钮：标准 36×36px，仅使用 Tooltip 和 `accessibleText` 补充语义。
- 危险按钮：默认白底红字红边，必须在确认动作中使用。
- 禁用态：保持可读，不透明度降级改为中性背景、边框和文字。
- 每个页面最多一个首要主操作；并列主按钮必须有清晰的任务优先级。

### 5.2 输入与选择

- 单行输入和选择器标准高度 40px，紧凑工具栏允许 36px。
- 输入文字 13px，左右内边距 13px。
- 默认边框 `-border`，悬停 `-border-hover`，焦点 `-border-focus`。
- 错误状态必须同时显示错误文字，不能只依赖颜色。
- 下拉列表项高度 38px，选中项使用 `-primary-soft`。

### 5.3 卡片与列表

- 卡片使用白色背景、10px 圆角、1px 边框和 `-shadow-card`。
- 列表行以边框和留白分隔，不使用大面积彩色背景。
- 统计卡图标容器使用 48–52px 的弱色方块，图标 24–27px。
- 可点击卡片悬停只改变边框和背景，不上浮。
- 空状态优先使用线性图标；只有确有视觉叙事价值时才使用插画。

### 5.4 筛选和标签

- 筛选项使用胶囊形，标准高度 30px，12px / 600。
- 选中筛选使用主色实底和白字。
- 状态标签使用弱色背景和同语义文字色，不使用渐变或阴影。
- 标签只展示短信息，长句必须进入正文或 Tooltip。

### 5.5 表格、弹层与滚动条

- 表头使用 `-surface-muted`，12px / 700；行高至少 46px。
- 选中行使用 `-primary-soft`，不得改变正文可读性。
- 菜单和下拉弹层圆角 10px，内边距 6px，使用 `-shadow-pop`。
- Tooltip 深色底、白字、圆角 6px。
- 滚动条保持低对比度，悬停时增强，不显示多余箭头按钮。

## 6. 图标规范

- 功能图标统一使用项目现有 Ikonli Material Design 2 线性图标。
- 标准尺寸：导航 19px、按钮 17–18px、统计 24–27px、空状态 36–40px。
- 默认图标使用 `-text-secondary`，选中或关键动作使用 `-primary`。
- 禁止使用 Emoji、Unicode 箭头、ASCII 图形或文字模拟功能图标。
- 图标按钮必须设置 `accessibleText`；语义不明显时必须提供 Tooltip。
- 不为标准功能操作生成位图图标。

## 7. 插画和图片素材

插画仅用于登录/注册主视觉、侧栏装饰和重要空状态。统一风格：

- 3D 软质黏土 / 轻等距视角，圆润几何结构。
- 哑光白、靛蓝、薰衣草紫为主，允许极少量浅蓝。
- 柔和环境光、低对比阴影、透明背景。
- 无文字、无品牌水印、无真实人物照片、无复杂场景背景。
- 导出 PNG，透明通道，源尺寸至少为最终显示尺寸的 2 倍。

标准生成提示词模板：

> A polished 3D clay-style isometric illustration for the AI Interviewer desktop application, [subject and action], matte white surfaces with indigo and soft lavender accents, rounded geometry, subtle translucent details, soft studio lighting, gentle ambient shadow, clean professional SaaS visual language, centered composition, transparent background, no text, no letters, no logo, no watermark, high fidelity.

## 8. 页面模板

标准业务页面结构：

1. 68px 页面头部：标题 + 说明 + 右侧主次操作。
2. 可选统计区：同高卡片，12px 间距。
3. 42px 工具栏：左侧筛选，右侧搜索、排序和刷新。
4. 主内容：白色卡片或高密度列表，允许纵向滚动。
5. 可选底部提示卡：仅承载下一步建议或状态说明。

详情页和编辑页使用相同页面背景、头部和按钮体系；返回操作使用 Material Design 左箭头图标，不使用字符箭头。

## 9. 交互与动效

- 按钮、输入、卡片的悬停反馈应在 100–140ms 内完成。
- 页面切换 160–200ms，抽屉 180–220ms，弹窗 160ms。
- 动画只用于解释状态变化：加载、进度、展开、保存反馈和登录主视觉轻微呼吸。
- 禁止粒子背景、鼠标跟随、持续发光边框、卡片漂浮和无业务意义的全页动画。
- 所有交互必须保持键盘焦点、可访问名称和清晰的成功/失败反馈。

## 10. 开发约束与验收

- 业务控制器、服务、数据模型和导航逻辑不得因视觉改造而改变。
- FXML 只声明结构、语义样式类和事件绑定；禁止 `style="..."`。
- 页面不得创建与通用类重复的局部按钮、输入框、卡片或标签标准。
- 新增页面必须先复用 `.page-title`、`.secondary-text`、`.content-card`、`.primary-button`、`.secondary-button`、`.back-icon-button` 等通用类。
- 视觉改动必须在 1672×901 基准画幅和 1366×846 窄画幅检查遮挡、裁切、横向滚动和文字可读性。
- 主要路由必须完成 JavaFX 原生截图、同画幅比较、FXML 加载和既有业务回归测试。
- 存在 P0、P1 或 P2 视觉问题时不得交付；QA 结果记录在项目根目录 `design-qa.md`。

### 页面验收清单

- [ ] 页面背景、标题、副标题、主操作与基准一致。
- [ ] 所有控件来自通用组件样式，没有内联样式。
- [ ] 图标来自 Material Design 2，没有 Emoji 或字符图标。
- [ ] 卡片、输入、按钮、标签的圆角、边框和高度符合规范。
- [ ] 长文本、空状态、加载、错误、禁用和选中态均可读。
- [ ] 1366px 窄画幅无覆盖、裁切或横向滚动。
- [ ] 业务行为、数据保存和导航闭环未改变。
- [ ] `design-qa.md` 最终结果为 `passed`。
