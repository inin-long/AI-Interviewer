## 用户注册和登录

### 注册

1. 启动应用，进入登录页面
2. 点击「注册」
3. 输入用户名、密码、昵称
4. 点击「确认」完成注册

### 登录

1. 输入用户名和密码
2. 点击「登录」

---

## 简历管理

### 上传简历

1. 进入「简历」页面
2. 点击「上传」按钮
3. 选择简历文件（PDF/DOCX/Markdown/TXT）
4. 等待系统解析完成

### 查看状态

简历有以下状态：

| 状态 | 说明 |
|------|------|
| 已上传 | 文件已上传，等待解析 |
| 解析中 | 正在提取文本内容 |
| 已完成 | 解析完成，可以使用 |
| 失败 | 解析失败，可以重新上传 |

### 候选人画像

简历解析完成后，系统自动生成候选人画像：

1. 进入「画像」页面
2. 查看 AI 生成的画像内容
3. 确认信息准确后点击「确认」

画像包含：
- 技能栈分析
- 项目经验提取
- 技术背景总结

## 知识库管理

### 上传知识文档

1. 进入「知识库」页面
2. 点击「上传」按钮
3. 选择文档文件
4. 等待系统处理（解析 → 分块 → 向量化）

### 知识库用途

上传的知识文档会在面试时被 AI 参考：

- AI 会根据你的知识背景生成更贴合的问题
- 回答时可以引用知识库中的内容
- 让面试更有针对性

---

## 面试方案

### 创建方案

1. 进入「面试方案」页面
2. 点击「创建方案」
3. 填写方案信息：
   - 方案名称
   - 目标岗位
   - 岗位描述（可选）
   - 难度等级
   - 面试时长
   - 问题数量
   - 关联简历
   - 关联知识库（可选）
4. 点击「保存」

### 方案配置

| 字段 | 说明 |
|------|------|
| 方案名称 | 自定义名称，方便识别 |
| 目标岗位 | 如「Java 后端工程师」 |
| 岗位描述 | 详细的 JD，AI 会据此调整问题 |
| 难度等级 | 简单 / 中等 / 困难 |
| 面试时长 | 预计面试时间 |
| 问题数量 | 预计问题数量 |
| 关联简历 | 选择要使用的简历 |
| 关联知识库 | 选择参考的知识文档 |

## 面试过程

### 开始面试

1. 在面试方案中点击「开始面试」
2. 进入面试工作台
3. AI 面试官会先让你做自我介绍

### 面试技巧

1. **认真回答**：AI 会根据你的回答质量决定是否追问
2. **可以暂停**：点击「暂停面试」可以随时中断
3. **使用代码**：复杂问题可以使用代码回答功能
4. **查看引用**：右侧栏会显示 AI 参考的知识文档

### 暂停和恢复

1. 点击「暂停面试」保存当前状态
2. 可以关闭应用
3. 下次进入「面试记录」找到未完成的面试
4. 点击「恢复面试」从断点继续

## 查看报告

### 报告内容

面试结束后自动生成报告：

1. **综合评分**：0-100 分
2. **六个维度**：
   - 技术能力
   - 问题解决
   - 项目经验
   - 系统设计
   - 沟通表达
   - 综合评价
3. **详细分析**：每个维度的具体评价
4. **改进建议**：针对性的学习方向

### 查看历史

1. 进入「面试记录」页面
2. 查看所有历史面试
3. 点击任一记录查看完整问答和报告

## 任务中心

后台任务（简历解析、知识处理、报告生成）的状态可以在任务中心查看：

1. 进入「任务中心」
2. 查看待处理和已完成的任务
3. 失败的任务可以手动重试

## 设置

### AI 服务配置

在「设置」页面配置 LLM 服务：

- Base URL：API 地址
- API Key：密钥
- Chat Model：聊天模型
- Embedding Model：向量模型
- 测试连接：验证配置

### 数据目录

查看和访问本地数据目录：

- 数据库位置
- 用户文件位置
- 日志位置
