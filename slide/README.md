# AI Interviewer 实训验收汇报

这是一份基于 [Slidev](https://sli.dev/) 的五分钟实训验收汇报，共 7 页。

## 本地运行

```powershell
corepack pnpm install
corepack pnpm dev
```

构建静态站点：

```powershell
corepack pnpm build
```

## 汇报结构

1. 项目定位与验收结论
2. 项目背景与解决思路
3. 业务闭环
4. 功能模块
5. 智能体核心链路
6. 技术选择
7. 实施分工与验收收束

演讲提示写在 `slides.md` 的 presenter notes 中，不会显示在观众页面。
