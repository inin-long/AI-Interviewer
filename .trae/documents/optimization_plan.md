# AI 模拟面试官 - 优化扩展计划

## 项目概览

这是一个基于 **Java + JavaFX + Spring Boot** 的桌面应用，核心功能包括：用户系统、简历管理、知识库（RAG）、AI 面试系统、报告生成、后台任务。当前 MVP 已完成，代码质量良好。

---

## 可优化扩展项

### 一、UI 体验优化（推荐优先）

#### 1. 暗色主题 (Dark Mode)
- **说明**：为应用添加深色主题，保护用户眼睛，提升夜间使用体验
- **涉及文件**：`app.css`、`SettingsController.java`、`main-window.fxml`
- **优先级**：⭐⭐⭐
- **难度**：中等

#### 2. 面试计时器
- **说明**：在面试页面添加实时计时器，显示当前题目用时和总用时
- **涉及文件**：`InterviewWorkspaceController.java`、`interview-workspace-view.fxml`、`app.css`
- **优先级**：⭐⭐⭐⭐
- **难度**：简单

#### 3. 回答时间限制提示
- **说明**：根据项目记忆，每道题有 3 分钟时间限制，超过自动扣分
- **涉及文件**：`InterviewWorkspaceController.java`、`InterviewAgentService.java`、`app.css`
- **优先级**：⭐⭐⭐⭐
- **难度**：中等

#### 4. 统一的 Loading/Empty/Error 状态组件
- **说明**：为表格和列表添加加载中、空数据、错误状态的统一展示
- **涉及文件**：新增组件文件、`app.css`
- **优先级**：⭐⭐⭐
- **难度**：中等

---

### 二、功能增强

#### 5. 面试报告导出
- **说明**：支持将面试报告导出为 PDF 或 Markdown 文件到桌面
- **涉及文件**：`InterviewReportController.java`、`app.css`
- **优先级**：⭐⭐⭐⭐
- **难度**：中等

#### 6. 面试方案模板
- **说明**：提供预设的面试方案模板（如：前端开发、后端开发、产品经理），快速创建面试
- **涉及文件**：`InterviewPlanEditorController.java`、`InterviewPlanService.java`
- **优先级**：⭐⭐⭐
- **难度**：中等

#### 7. 面试历史筛选与搜索
- **说明**：在面试历史页面添加按时间、岗位、状态筛选和关键词搜索功能
- **涉及文件**：`InterviewHistoryController.java`、`InterviewHistoryService.java`、`history-view.fxml`
- **优先级**：⭐⭐⭐
- **难度**：中等

#### 8. 键盘快捷键支持
- **说明**：添加常用快捷键，如：Enter 提交回答、Ctrl+Enter 换行、Esc 暂停面试
- **涉及文件**：`InterviewWorkspaceController.java`、`interview-workspace-view.fxml`
- **优先级**：⭐⭐⭐
- **难度**：简单

---

### 三、稳定性与代码质量

#### 9. 网络中断优雅降级
- **说明**：当 AI 服务连接中断时，给出友好提示并保存当前状态
- **涉及文件**：`OpenAiChatService.java`、`GlobalExceptionHandler.java`、`InterviewWorkspaceController.java`
- **优先级**：⭐⭐⭐⭐
- **难度**：中等

#### 10. API Key 加密存储
- **说明**：使用 AES-256 加密存储 API Key，增强安全性
- **涉及文件**：`LlmProperties.java`、`SecurityConfiguration.java`
- **优先级**：⭐⭐⭐⭐⭐
- **难度**：中等

#### 11. 添加详细注释
- **说明**：为核心代码添加中文注释，便于理解和维护
- **涉及文件**：所有核心 Controller、Service、Agent 相关文件
- **优先级**：⭐⭐⭐
- **难度**：简单

## 需要确认的问题

以下几点需要你确认后再开始执行：

1. **优先做哪些？** - 上面列出了很多优化项，你最想先实现哪几个？
2. **报告导出格式** - 你希望导出 PDF、Markdown，还是两者都支持？
3. **时间限制规则** - 每道题 3 分钟是硬性限制（超时自动提交）还是只是警告提示？
4. **暗色主题开关** - 你希望在设置页面添加主题切换开关吗？

## 风险评估

| 风险项 | 风险等级 | 应对措施 |
|-------|:---:|---------|
| API Key 加密可能影响现有配置 | 中 | 保留明文配置作为兼容选项，新增加密配置 |
| 网络中断处理可能引入新的异常 | 低 | 添加详细测试用例 |
| 暗色主题可能导致部分组件样式问题 | 低 | 逐步测试并调整 CSS |
